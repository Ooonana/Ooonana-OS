# Ooonana OS 0.1.8

Full i3 live and installer release focused on native desktop controls, hardware reliability, and non-root daily use.

## Highlights

- Native GTK3 Settings, AI chat, Wi-Fi, Bluetooth, Packages, quick controls, first-boot setup, and application launcher
- Icon-first Ooonana polybar with audio, brightness, battery, Bluetooth, Wi-Fi, clock, window, and power controls
- Desktop runs as `ooonana` UID 1000; wheel administration uses validated `doas`
- NetworkManager, BlueZ, rfkill, Wi-Fi firmware, Bluetooth firmware, audio, GPU, touchpad, keyboard, Ethernet, and SD-card support included
- Larger centered orange boot logo and progress bar
- Hybrid BIOS/UEFI GRUB image for Rufus ISO mode
- Read-only live boot unless installation or persistence is explicitly selected
- GitLab cloud package repo enabled by default; package archives download only when installed
- Native `ooonana-core` update package lets `ooonana update && ooonana upgrade` refresh CLI, desktop apps, services, defaults, and game
- Ooonana package manager 0.8.3 downloads and verifies remote archives before replacing installed files; migration-safe core/runtime packages bootstrap older images
- WSL full desktop image updated with WSLg support and non-root default login
- Runtime mounts now provide `/var/run -> /run` and tmpfs `/dev/shm` before desktop services
- System D-Bus now starts before NetworkManager and BlueZ, fixing live USB Wi-Fi, Bluetooth, Chromium, and repair startup
- Power actions report real shutdown/restart failures instead of silently succeeding
- Upgraded `oonana` brickout game uses compact logo ball, colored `OOONANA OS` bricks, pause/restart/speed controls, and row-diff rendering
- Blueman mechanism uses custom-init startup; applet launches only when Bluetooth controller exists

## Validation

- Full shell test suite

## USB

Use Rufus **ISO Image mode (Recommended)**. The ISO supports legacy BIOS and UEFI. Disable Secure Boot for this unsigned release. For persistence, add an ext4 partition labeled `OOONANA_PERSIST` and choose the persistent live GRUB entry.

The ISO is split into numbered parts because GitHub release assets cannot hold the complete image as one file. Follow `REASSEMBLE.txt`, then verify `SHA256SUMS.full-i3` before flashing.
