## Release blockers / remaining work

1. **Chromium sandbox crash:** actual candidate exits after `seccomp-bpf failure in syscall nr=0x148`, including GPU process exit 139. Chromium's [syscall table](https://new.chromium.org/chromium-os/developer-library/reference/linux-constants/syscalls/) identifies x86_64 syscall 328 as `pwritev2`. Alpine's [musl sandbox patch](https://raw.githubusercontent.com/alpinelinux/aports/3.24-stable/community/chromium/musl-sandbox.patch) adds it to renderer policy, not general/GPU baseline. Libc/policy mismatch is suspected, not yet conclusively isolated from chroot environment. Requires corrected upstream/source build and sandbox-enabled retest; do not mask failure with `--no-sandbox` or mixed-branch libc.
2. **Desktop session validation:** isolated Nemo compositor gate now passes after correcting glyph-sensitive readiness measurement and waiting for actual painted fill. Production redraw code stayed unchanged. Full new-base GTK/Qt/dialog/file-picker and WSLg/physical sessions still require interactive validation; do not use earlier premature captures as README proof.
3. **Installed Ooonana WSL migration deferred by user.** Full backup must complete and verify first. Attempted compressed export was stopped for F: space pressure, not accepted as a backup. Offline VHD access additionally needs a supported elevated/independent environment; current Windows shell is not elevated. Resolve retired APKs, including old upstream Neofetch, explicitly before replacing libraries. Preserve accounts/config/checkpoints/models/history.
4. **Release prep:** candidate stays separate from stable channel. Rebuild final rootfs/manifest from committed source after browser/visual fixes, then disposable BIOS/UEFI/service/login/GUI gates. Existing 0.9.9 cached stage cannot resume as 0.10. ISO building stays user-owned; no ready-release claim yet.
5. **PDF/runtime gates:** optimize measured slow package list/sync without removing verification or altering real package backend. Real nonroot Firefox Flatpak setup/portals/file pickers/update; OpenVINO Linux runtime/model loading, streaming/cancel, low-memory and API restart recovery. Fixture APIs/imports are not real inference.
6. **Physical gates:** fresh disposable USB persistence power loss/full storage/recovery, interrupted installed upgrade/rollback, Wi-Fi/Bluetooth/audio controls, GPU, thermals/fans. Mixed DPI/monitors/hotplug, Korean IME, keyboard/mouse WSLg, login/lock/suspend/resume remain interactive/device gates.
7. **Trust:** signing enrollment and CI private-key upload remain deferred. Local signature validation is not automatic client enrollment.
