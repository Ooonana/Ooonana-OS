## Release blockers / remaining work

1. **Chromium image/session validation:** optional shader disk cache isolated the `pwritev2` syscall crash; global wrapper config/current launcher disable only that cache. Private compositor/window actions and actual renderer/GPU `Seccomp=2`, `NoNewPrivs=1` passed. Sandbox and normal GPU selection retained. Fresh image-kernel browser/physical GPU checks remain, not a requirement to disable sandbox or mix libc. [Upstream cache switch](https://chromium.googlesource.com/chromium/src.git/+/refs/heads/main/gpu/config/gpu_switches.cc).
2. **Desktop session validation:** a later run reproduced genuine black Nemo controls despite corrected fill measurement. RGBA visual selection before realize and shape-damage redraw fixed repeated captures; all eleven isolated GUI gates passed. Full new-base GTK/Qt/dialog/file-picker and WSLg/physical sessions still require interactive validation; current README captures are clearly labeled private fixtures.
3. **Installed Ooonana WSL migration deferred by user.** Full backup must complete and verify first. Attempted compressed export was stopped for F: space pressure, not accepted as a backup. Offline VHD access additionally needs a supported elevated/independent environment; current Windows shell is not elevated. Resolve retired APKs, including old upstream Neofetch, explicitly before replacing libraries. Preserve accounts/config/checkpoints/models/history.
4. **Release prep/storage:** candidate stays separate from stable channel. Rebuild final rootfs/manifest from committed source, then fresh-image BIOS/UEFI/service/GUI gates. Existing 0.9.9 cached stage cannot resume as 0.10. F: ~4.2 GiB free is below builder's 8 GiB minimum; large builds/backup need more space. ISO building stays user-owned; no ready-release claim yet.
5. **PDF/runtime gates:** verified snapshot listing reduced Node list ~130 -> 45s and sync ~86 -> 57s. Cache hardening exposed missing TinyEMU `rdtime`; CLINT-backed time CSR/privilege fix passed compiled guards and final shipped boot/input/Backspace/edit/version/sync in 87s. Actual PDF viewer remains manual/policy-blocked. Real nonroot Firefox Flatpak setup/portals/file pickers/update; OpenVINO Linux runtime/model loading, streaming/cancel, low-memory and API restart recovery remain. Fixture APIs/imports are not real inference.
6. **Physical gates:** disposable 6.18.37 QEMU partition and full ext4/FAT file persistence fault/recovery suites, dirty-FAT refusal, failed-shutdown hold, upgrade interruption/config rollback and nonroot login passed. These do not certify physical USB/installed targets. Wi-Fi/Bluetooth/audio controls, GPU, thermals/fans, mixed DPI/monitors/hotplug, Korean IME, WSLg keyboard/mouse, lock/suspend/resume remain device/session gates.
7. **Trust:** signing enrollment and CI private-key upload remain deferred. Local signature validation is not automatic client enrollment.
